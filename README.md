# Mobaryn

> Bengkel mobil panggilan — website monorepo

## Structure

```
mobaryn/
├── apps/
│   └── web/          # React + Vite + Tailwind CSS frontend
├── server/
│   └── supabase/     # Supabase migrations, seed, and edge functions
└── docs/             # Project documentation
```

## Getting Started

```bash
cd apps/web
npm install
npm run dev
```

## Stages

- **Stage 1** ✅ Project skeleton & folder structure
- **Stage 2** 🔜 Database schema & Supabase setup
- **Stage 3** 🔜 UI design tokens & component styling
- **Stage 4** 🔜 Page content & business logic
